# 0004 — Reeds inside the stops; magnets on the 60 mm double horn; catch magnets removed

**Context.** Earlier catch magnets (to hold the valve) interfered with the reeds. Earlier horn-flag/bracket mounts (see legacy) were fiddly.

**Decision.** Reed switches embedded in the printed stops behind ~1 mm plastic; magnets on the 60 mm double horn so each end of the horn hits one stop. Catch magnets removed.

**Consequences.** Both stops sensed → actual state; both-ON = fault.
