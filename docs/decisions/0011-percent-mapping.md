# 0011 — open % / closed % mapping

**Context.** Early configs mapped open→0 %, closed→100 %. Each valve's horn mounts at a different angle.

**Decision.** Signed −100…100 % per gate with separate open/closed numbers (current defaults CNC 45/−69, Hose 69/−42).

**Consequences.** Calibrate after any horn re-mount.
